## 🎓 ABC Institute Student Analytics Dashboard — Power BI

This project is an **interactive Student Analytics Dashboard developed using Microsoft Power BI** for analyzing student enrollment and course-related information at ABC Institute.

The dashboard transforms student and course data into meaningful visual insights covering **student enrollment trends, course-wise fee analysis, age distribution, total fees, student information, and city-wise filtering**. Interactive slicers allow users to explore the data by **year, city, and course**, making the dashboard useful for understanding student enrollment patterns and course performance.

### 📊 Key Analysis

The dashboard provides insights into:

* **Student Enrollment Trends** – Analyze the number of students joining courses over time.
* **Course-wise Analysis** – Compare the number of enrollments and fees associated with different courses.
* **Fee Analysis** – Understand the total fee generated across available courses.
* **Age Distribution** – Analyze students based on different age groups.
* **Student Information** – Display important student-level information and metrics.
* **City-wise Analysis** – Filter and explore student data based on location.
* **Year-wise Analysis** – Examine enrollment patterns across different years.

### 🛠️ Tools Used

* **Microsoft Power BI** – Dashboard development and visualization
* **Power Query** – Data transformation and preparation
* **DAX** – Calculations, measures, and KPIs
* **Data Visualization** – Charts, cards, gauges, slicers, and interactive filtering

### 📌 Dashboard Features

The dashboard includes:

* Student enrollment trend chart
* Course-wise fee comparison
* Age distribution visualization
* Total fees KPI
* Student-related KPI cards
* Interactive year slicer
* City slicer
* Course slicer
* Interactive and dynamic filtering

### 🎯 Project Objective

The primary objective of this project is to demonstrate how **Power BI can be used to convert student and course data into an interactive analytical dashboard** that helps institutions understand enrollment patterns, course demand, fee performance, and student demographics.
